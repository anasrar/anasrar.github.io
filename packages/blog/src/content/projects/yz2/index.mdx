# yz2

Tool for decompress and recompress file, mostly use by Capcom on PlayStation 2 era, very popular on Resident Evil 4 modding community.

This one is rewrite from Python script that https://github.com/Falkrian posted on https://reshax.com/topic/618-ps2-sengoku-basara-2/

## Usage

```bash
## decompress
yz2 inputfile outputfile
## recompress
yz2 -c inputfile outputfile
```
